PicoScanner is an RFID makerspace access and station-use system. Serena project root is C:\Users\xtras\jwuuu07.github.io\PicoScanner; live code is under Code, with no Code\Original directory despite the session cwd metadata. Main server files are Code\Pi 3\app.py, dashboard.html, config.json, requirements.txt, station-server.service, test_app.py, and seed_analytics_demo.py. The backend is a single large Flask app using SQLite, openpyxl exports, in-memory login sessions, certification timers, and kit swipe-pair timers. Main API surfaces include /swipe, /api/test-swipe, /health, /dashboard, /api/dashboard, /api/access, /api/admin, card/station/certification/kit endpoints, analytics, XLSX export, and CSV exports. Database tables are created in init_db and include stations, active_people, active_sessions, people, cards, user_accounts, certifications, bronco_certifications, certify_permissions, canvas_sync_tasks, swipe_events, pending_card_dismissals, warning_dismissals, audit_log, kits, and kit_checkouts. Pico W firmware lives in Code\Pico W. Reader scripts share MFRC522 RFID reads, a limit switch trigger, NeoPixel LED states, optional GP14 buzzer feedback, HTTP POSTs to the Flask /swipe endpoint with X-Station-Key, event_id idempotency, and OfflineQueue retry storage. Repeated station readers are specialized mainly by STATION_ID, STATION_NAME, and STATION_KIND. Key helpers are mfrc522.py and offline_queue.py. Tests are unittest-based in Code\Pi 3\test_app.py and cover security, login rate limiting, role enforcement, swipe idempotency, dashboard privacy, certifications, station sessions, kit checkout, Canvas import/sync, exports, warnings, and analytics-relevant flows. README test command is ./venv/bin/python -m unittest -v test_app.py from Code\Pi 3 on the Pi. Deployment uses gunicorn with one worker and four threads because server-side sessions/timers are in memory. Operational caution: several Pico scripts contain placeholder or literal test Wi-Fi/API key values such as MS, Ms2019!!, and key; avoid committing or deploying real secrets in these files.
